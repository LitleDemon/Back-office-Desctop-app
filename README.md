# ShopEcosystem — Back-office

Внутренняя система (API + Desktop) для управления сетью супермаркетов. Проект представляет собой монорепозиторий, объединяющий бэкенд, десктопное приложение и общие пакеты (база данных).

## 🛠 Стек технологий
* **Бэкенд:** Node.js, TypeScript, Fastify, Prisma ORM, JWT (авторизация)
* **База данных:** MySQL 8 (в Docker)
* **Фронтенд (Desktop):** React, Vite, React Router DOM
* **Инфраструктура:** Docker Compose, npm workspaces (монорепозиторий)

## 📂 Структура проекта
```text
Back-office/
├── apps/
│   ├── api/          # Бэкенд сервер (Fastify + TypeScript)
│   └── desktop/      # Интерфейс (React + Vite)
├── packages/
│   ├── db/           # Prisma схема, миграции и сиды
│   └── shared/       # Общие типы (в разработке)
├── docker-compose.yml
└── package.json      # Корневой файл (управление воркспейсами)
```

## 🚀 Быстрый старт

### 1. Требования
Убедитесь, что у вас установлены:
* **Node.js** (версия 20 или выше)
* **Docker Desktop** (с настроенным WSL 2)
* **Git**

### 2. Установка зависимостей
В корне проекта выполните:
```bash
npm install
```

### 3. Запуск базы данных (Docker)
Убедитесь, что Docker Desktop запущен, и выполните:
```bash
docker compose up -d
```
* MySQL будет доступен на порту `3307`.
* Adminer (веб-интерфейс для БД) будет доступен на порту `8080`.

### 4. Настройка базы данных (Prisma)
Примените миграции для создания таблиц и заполните базу тестовыми данными:
```bash
npm run db:migrate
npm run db:seed
```

### 5. Запуск проекта
Откройте **два терминала** в корне проекта:

**Терминал 1 — Бэкенд (API):**
```bash
npm run dev:api
```
* API будет доступно по адресу: `http://localhost:3000`

**Терминал 2 — Фронтенд (Desktop):**
```bash
npm run dev:desktop
```
* Интерфейс будет доступен по адресу: `http://localhost:5173`

## 🚦 Что уже реализовано

* **Монорепозиторий:** Настроены workspaces для совместной работы API и фронтенда.
* **База данных:** Схема описывает Города, Точки (Склады/Магазины), Пользователей, Роли, Товары, Клиентов и Заказы.
* **Авторизация (JWT):** Логин по email/паролю. Защита API-роутов и скрытие пунктов меню на основе ролей (RBAC).
* **Каталог:** Вывод списка товаров из БД.
* **Касса (POS):**
  * Поиск товаров по названию и артикулу (SKU).
  * Формирование корзины (чека) с подсчетом итоговой суммы.
  * Оплата картой (имитация с шансом 95% на успех).
  * Оплата с внутреннего баланса клиента (по 6-значному коду).
  * Сохранение истории продаж в БД (с фиксацией `priceSnapshot` на момент продажи).

## 💻 Полезные команды (из корня проекта)

* `npm run db:generate` — пересобрать Prisma Client (после изменения `schema.prisma`).
* `npm run db:migrate -- --name имя_миграции` — создать и применить новую миграцию.
* `npm run db:seed` — заполнить базу тестовыми данными (города, товары, юзеры).
* `npm run db:studio` — открыть Prisma Studio (альтернативный просмотрщик БД).
