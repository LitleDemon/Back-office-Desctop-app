# ShopEcosystem - Back-office

Внутренняя система (API + Desktop) для управления сетью супермаркетов.

## 🚀 Как запустить проект

### 1. База данных (Docker)
Убедись, что Docker Desktop запущен (зеленая иконка в трее).
```bash ```
docker compose up -d 
### 2. Бэкенд (API)
Запусти сервер в режиме разработки (с авто-перезагрузкой):

bash
npm run dev:api
API будет доступно по адресу: http://localhost:3000

### 3. Просмотр базы данных (Adminer)
Открой в браузере: http://localhost:8080

### ☀️ 2. Твой "Ежедневный ритуал" запуска

Каждый раз, когда ты включаешь компьютер, чтобы поработать над проектом, алгоритм такой:

1. **Ждёшь Docker:** Смотришь в трей (возле часов). Убедись, что Docker Desktop запустился (кит перестал крутиться). Если нет — запусти его вручную.
2. **Открываешь VS Code:** Открываешь папку `Back-office`.
3. **Открываешь терминал:** Нажимаешь `Ctrl + ~`.
4. **Запускаешь API:** Пишешь `npm run dev:api`.
5. **Начинаешь работать:** Открываешь браузер для тестов (`localhost:3000`).

*(Команду `docker compose up -d` делать каждый раз не нужно, так как мы настроили автозапуск, но если вдруг контейнеры не поднялись — просто введи её).*
